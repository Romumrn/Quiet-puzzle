Quiet Puzzle — a mobile puzzle game where players make blocks exit through color-coded doors. It is a web prototype with no build dependencies: plain HTML, CSS, and native JavaScript (ES modules).

```
prototype/          source files — this is where development happens
prototype/levels/   the level base in JSON — what the game actually reads
prototype/images/   the map decorations, one branch per world
prototype/docs/     documentation: level creation, map decoration
docs/               the published site — modular sources, generated by tools/publier.mjs
media/              screenshots for the README
```
